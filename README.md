# Бросить курить

Минималистичное бесплатное Android-приложение для отказа от курения. Первая рабочая версия, 0.1.0. Android 8.0 и новее. Работает офлайн, без аккаунта, рекламы, аналитики и сетевых разрешений.

## Что работает

- Знакомство в три шага: сигареты, вейп, стики; можно выбрать несколько продуктов. Начальная оценка количества, дата отказа, личная причина.
- Быстрая отметка с отменой; дневник с датой, временем, количеством и причиной. Добавление пропущенных записей, редактирование и удаление.
- Отдельный дневной предел для каждого продукта. Человек подтверждает изменение; превышение не повышает предел автоматически. С даты полного отказа цель — ноль.
- Календарь по месяцам: нажать на дату и ввести общее количество за день для каждого продукта. Ноль означает отсутствие употребления, пустое поле — неизвестное количество. Можно внести историю до начала использования приложения.
- Итог за день включает уже сделанные отдельные отметки. Новые отметки увеличивают итог, редактирование и удаление меняют его на соответствующую разницу. Отдельно подтверждать день не нужно; старые записи и подтверждения поддерживаются.
- Среднее за последние прошедшие дни с итоговым числом, число дней без употребления и росток достижений. Дни без итогового числа не считаются нулями. Числа с точкой в календаре показывают отдельные отметки без общего итога.
- Помощь при тяге и трёхминутный таймер, который восстанавливается после закрытия экрана или перезапуска приложения.
- Отключаемое Android-напоминание записать итог дня около 20:30; запрашивает разрешение на Android 13+. После перезагрузки устройства расписание восстанавливается. Доставка может задерживаться системой.
- Личная причина отказа, справка со ссылками, удаление данных с подтверждением.
- Светлая и тёмная темы: переключатель в настройках, выбор сохраняется на устройстве. В Android меняется также оформление системных панелей. Прокрутка ограничена областью приложения, поэтому содержимое не появляется ниже нижнего меню в браузере.

## Установка тестовой версии

Файл `dist/brosit-kurit-0.1.0-debug.apk` — APK с отладочной подписью для проверки на телефоне. Перенесите его на Android-устройство, откройте и разрешите установку для приложения, которым открываете APK, если Android попросит.

Это ещё не релиз для RuStore: публикация не выполнялась. Для магазина нужны постоянная подпись владельца, финальный идентификатор приложения, оформление карточки и проверка на устройствах. Не используйте отладочный ключ как ключ будущего релиза.

Данные сохраняются локально. Удаление приложения или его данных удалит дневник. Экспорта и синхронизации в этой версии нет. Резервирование и перенос через системные механизмы Android исключены настройками приложения.

## Предпросмотр на компьютере

Нужен Node.js. Из корня проекта:

```powershell
node scripts/preview.cjs
```

Открыть http://127.0.0.1:4173. Интерфейс тот же; данные браузера хранятся отдельно от APK, Android-уведомления в браузере недоступны.

## Сборка

Java 17, Android SDK Platform 35, Build Tools 35.0.0. Gradle Wrapper включён в проект. В Android Studio откройте папку проекта и дождитесь настройки SDK. Или задайте `ANDROID_HOME`; локальный путь SDK можно записать в неотслеживаемый `local.properties`.

```powershell
.\gradlew.bat assembleDebug lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Путь Windows в `local.properties` требует экранированного двоеточия, например `sdk.dir=C\:/Android/Sdk`. Флаг `android.overridePathCheck=true` позволяет собирать проект из текущего пути с кириллицей. На системах без этой особенности его можно убрать.

## Проверки

```powershell
node --test tests/core.test.cjs
```

Сквозная проверка интерфейса использует Playwright. Установите его в своём окружении (`npm install --no-save playwright`, затем `npx playwright install chromium`), запустите предпросмотр и выполните:

```powershell
node tests/ui.test.cjs
```

При необходимости `CHROMIUM_PATH` задаёт путь к имеющемуся Chromium. Снимки экранов сохраняются в `test-results/`.

Проверены: расчёты дней и средних, разграничение продуктов, объединение эпизодов вейпа, изменение/удаление записей, месячный календарь, исторические итоги, отсутствие двойного счёта, ноль и неизвестное количество, пределы и дата отказа, сохранение профиля, восстановление таймера, узкий экран 320 px. Android-сборка и lint проходят. Проверка на физическом телефоне и доставка уведомлений ещё не выполнялись: устройство не подключено.

## Устройство проекта

Интерфейс написан на HTML/CSS/JavaScript и упакован в Android WebView. Нативная оболочка на Java сохраняет дневник в закрытые SharedPreferences и управляет уведомлениями. Сторонних библиотек в APK нет. Веб-страницы извне в WebView не открываются; ссылки на источники передаются системному браузеру.

- `app/src/main/assets/core.js` — чистые правила дневника и расчётов.
- `app/src/main/assets/app.js` — интерфейс и сценарии.
- `app/src/main/assets/style.css` — оформление.
- `app/src/main/java/ru/shag/quit/` — Android-оболочка и напоминания.
- `tests/` — проверки расчётов и интерфейса.

## Границы продукта

Число эпизодов вейпа не измеряет дозу никотина и не переводится в сигареты. Отметки вейпа с последовательными перерывами менее 10 минут объединяются в эпизод в рамках календарного дня. Это условное правило дневника.

Предложение «минус один» — пример шага для выбора пользователем, не медицинское назначение. Эффективность приложения отдельно не исследована. Материалы ориентированы на взрослых и не заменяют помощь специалиста. Медицинские источники доступны внутри приложения.
